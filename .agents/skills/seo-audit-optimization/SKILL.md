This skill provides comprehensive instructions, schemas, and best practices for achieving and maintaining Rank #1 visibility on Google and search engines for Tribeni Minati Foundation, Minati NGO Tribeni, and localized West Bengal social impact keywords.

   - Supply `FAQPage` schema for instant Google Rich Answer Box snippets.

3. **Core Web Vitals & Technical Standards**:
   - LCP < 2.0s via image compression (WebP/AVIF) and explicit dimensions.
   - CLS = 0 with reserved aspect ratio containers.
   - Exact `hreflang` tags (`en-IN`, `bn-IN`, `x-default`).
   - Clean canonical URLs, valid `sitemap.xml`, and open `robots.txt`.
