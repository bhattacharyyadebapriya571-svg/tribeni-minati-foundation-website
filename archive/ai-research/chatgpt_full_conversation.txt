# আমি হলে এভাবে করতাম

তুমি যেহেতু Windows ব্যবহার করছ, **PowerShell-এর একটা master installer** বানিয়ে নিতাম।

### Step 1 — Claude Code install

PowerShell খুলে:

```powershell
irm https://claude.ai/install.ps1 | iex
```

এটাই Anthropic-এর বর্তমানে recommended native Windows installer। Native Windows-এ Git for Windows থাকাও recommended। citeturn8search0turn8search1

তারপর:

```powershell
claude
```

Login করে বেরিয়ে আসো।

# Step 2 — একবারে official 20-ish plugins install

Claude Code বন্ধ করে PowerShell-এ এই পুরো block চালাতে পারো:

```powershell
$plugins = @(
    "superpowers",
    "frontend-design",
    "code-review",
    "context7",
    "skill-creator",
    "playwright",
    "notion",
    "canva",
    "slack",
    "linear",
    "github",
    "figma",
    "zapier",
    "asana",
    "stripe",
    "vercel",
    "remember",
    "exa"
)

foreach ($plugin in $plugins) {
    Write-Host "`n========================================" -ForegroundColor Cyan
    Write-Host "Installing: $plugin" -ForegroundColor Yellow
    Write-Host "========================================" -ForegroundColor Cyan

    claude plugin install "$plugin@claude-plugins-official" --scope user
}
```

Claude Code officially supports non-interactive `claude plugin install`, so this is exactly the sort of thing its plugin system is designed to automate. citeturn7search0

তারপর:

```powershell
claude plugin list
```

এবং Claude Code খুলে:

```text
/reload-plugins
```

# Step 3 — Claude HUD

HUD-টা official Anthropic plugin নয়; এটা Jarrod Watts-এর community plugin। এর marketplace আলাদা।

```powershell
claude plugin marketplace add jarrodwatts/claude-hud
claude plugin install claude-hud --scope user
```

তারপর Claude Code-এর মধ্যে:

```text
/reload-plugins
```

এবং:

```text
/claude-hud:setup
```

Claude HUD-এর official repo-তে এই marketplace installation flow-টাই দেওয়া আছে। citeturn0search10

# Step 4 — ToolRouter

এখানে সবচেয়ে interesting ব্যাপারটা হলো **ToolRouter নিজেই একটা unified MCP gateway**।

তোমার ছবিতে 165+ tools / 800+ skills লেখা থাকলেও বর্তমান ToolRouter documentation এখন **227+ tools / 1212 skills** দেখাচ্ছে — অর্থাৎ ছবির সংখ্যাগুলো ইতিমধ্যেই outdated। citeturn5search1

Claude Code-এ:

```powershell
claude mcp add --scope user toolrouter -- npx -y toolrouter-mcp
```

তারপর:

```powershell
claude mcp list
```

ToolRouter-এর current Claude Code guide-ও এই ধরনের `npx -y toolrouter-mcp` setup দেখাচ্ছে। citeturn5search4

**এটা খুব useful**, কারণ ভবিষ্যতে নতুন MCP tool লাগলে প্রতিবার আলাদা MCP install না করেও ToolRouter-এর মাধ্যমে পাওয়া যেতে পারে।

# Step 6 — Obsidian

এটা একটু আলাদা।

Obsidian নিজে Claude plugin marketplace-এর সাধারণ Claude Code plugin নয়। তোমার Obsidian vault-কে Claude-এর knowledge vault হিসেবে ব্যবহার করতে হলে Obsidian-এর মধ্যে একটি MCP/Claude Code plugin লাগবে।

একটা workable option:

**Obsidian → Community Plugins → `Claude Code` / `Claude Code MCP`**

অথবা GitHub-based MCP connector।

উদাহরণ হিসেবে `obsidian-claude-code-mcp` Claude Code-এর সঙ্গে Obsidian vault connect করে এবং MCP-এর মাধ্যমে notes/files access দেয়। citeturn5search5

**আমি তোমার জন্য এর মধ্যে কোনটা best সেটা বেছে দিতে পারি**, কারণ Obsidian-এর ক্ষেত্রে vault structure অনুযায়ী choice করা ভালো।

আমি তোমাকে **একটা ready-to-use Antigravity Powerhouse Pack** বানিয়ে দিতে পারি।

মানে তুমি শুধু:

```text
1. Folder download
2. Antigravity-তে open
3. One setup command
4. Google/GitHub/etc. account authorization
5. Done
```

এরপর তোমার Antigravity agent-কে বলতে পারবে:

```text
Review this code.
```

সে Code Review skill ব্যবহার করবে।

```text
Build a modern landing page.
```

সে Frontend Design skill ব্যবহার করবে।

```text
Search the latest official React documentation.
```

Context7/Exa-type MCP ব্যবহার করবে।

```text
Check my GitHub issue #123.
```

GitHub MCP ব্যবহার করবে।

```text
Find this project document in Drive.
```

Drive MCP ব্যবহার করবে।

```text
Search my Notion knowledge base.
```

Notion MCP ব্যবহার করবে।

```text
Test this website in Chrome.
```

Playwright/browser tooling ব্যবহার করবে।

এবং এগুলো **Claude-এর subscription ছাড়াই Antigravity environment-এর মধ্যে** করা যাবে—যদিও কোনো external service-এর API/OAuth বা paid quota লাগলে সেটা আলাদা বিষয়।

## একটা গুরুত্বপূর্ণ সতর্কতা

ছবিতে লেখা:

> **"25 Things to Install in Claude"**

এটা দেখে ২৫টা জিনিসকে ২৫টা software ধরে নিও না।

বাস্তবে:

**Skill ≠ MCP ≠ Plugin ≠ Connector ≠ Application**

এটাই পুরো ব্যাপারটা।

Antigravity এই পাঁচ ধরনের extensibility-কে অনেকটা এক জায়গায় আনছে। citeturn0search9turn0search1

### তাই তোমার টাকা না থাকার situation-এ আমার recommendation:

**Claude Code কিনতে যেও না।**

আমরা বরং:

> **Antigravity + Free/official MCPs + open-source Skills + তোমার existing GitHub/Google accounts**

দিয়ে যতটা সম্ভব **Claude Code-এর equivalent development environment** বানাব।

এবং আমি চাইলে তোমার জন্য **এই ২৫টার একটা একটা করে current 2026-compatible Antigravity version verify করে, তারপর একটাই master `setup.ps1` + `.agents` folder + `mcp_config.json` তৈরি করে দিতে পারি**—যাতে তুমি শুধু Antigravity-তে খুলে setup করো।
